# 0.8.9 generated-skin verifier alignment

Version 0.8.8 changed the generated Estuary Pictures Home providers from direct built-in URLs such as `recent-taken?...` to nine persistent `home-slot?slot=N` providers. The runtime tests and generated skin were updated, but `tools/verify.py` still required the removed `recent-taken` URL. Full GitHub builds therefore failed after the skin had been generated successfully.

Version 0.8.9 updates release verification to require all nine `home-slot` providers instead. A regression test runs the same verifier against the generated Estuary fixture and confirms that a missing slot fails closed.

This patch does not alter runtime Home behavior, the database schema or the generated Estuary patch revisions. It only aligns the release/build contract with the 0.8.8 Home architecture.
