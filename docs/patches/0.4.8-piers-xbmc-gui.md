# 0.4.8 Estuary GUI compatibility pin

Kodi add-on checker 0.0.36 advised the generated Piers skin to declare
`xbmc.gui` version `5.17.0`. The generated skin previously retained whatever
value was present in the downloaded upstream Estuary `addon.xml`, so the result
could vary when Kodi changed that declaration.

Version 0.4.8 makes the compatibility level explicit per Estuary channel and
sets both the Omega and Piers channels to the validated value `5.17.0`. The
builder rewrites the dependency during generation and regression tests start
with a deliberately different upstream value to prove the pin is applied.

Because the generated skin metadata changes, the Omega skin revision advances
from 12 to 13 and the Piers revision advances from 10 to 11. The plug-in advances
to 0.4.8 so release tags and source archives remain aligned. Database schema 5
and repository add-on version 0.2.26 are unchanged.
