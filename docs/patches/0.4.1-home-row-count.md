# 0.4.1 reliable home-screen row count

Version 0.4.1 fixes the row-count regression introduced when 0.3.5 separated
home-screen limits from normal widget limits.

Kodi 20 and newer expose typed add-on settings through `Settings.getInt()`. The
plug-in now uses that API for integer settings and falls back to the legacy
string reader on older Kodi versions. The home provider always uses the freshly
loaded `home_widget_limit`; an old cached URL containing `limit=10` is ignored.

Estuary keeps a fixed capacity of 40 items and no longer embeds the selected
count in its provider URL. The Home-window generation value remains in the URL
solely to make Kodi request fresh content after a settings change.

The service logs the loaded count and changes to it, making future diagnostics
unambiguous. No database migration or rescan is required.
