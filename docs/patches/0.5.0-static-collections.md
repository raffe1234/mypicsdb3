# 0.5.0 manual collections

Version 0.5.0 introduces named manual collections as a separate feature from
saved smart collections. A manual collection contains the exact indexed
pictures and home videos selected by the user; a smart collection remains a
live validated query.

The main menu gains **Collections**. Users can create a collection, rename it,
delete it without deleting media, and open it using **Default album view**.
Every normal indexed media item gains **Add to collection** in its context menu.
Inside a collection, **Remove from collection** removes only the reference.
Duplicate additions are reported but not inserted.

Collection rows preserve insertion order. Picture-only collections start Kodi's
picture playlist and video-only collections start its video playlist. Mixed
collections ask the user to choose one of those safe playback types; this avoids
Kodi 21 on Windows routing the probe image through VideoPlayer. Playback can be
started from the collection action or from a selected item. Missing media and
items hidden by the active rating policy are skipped safely.

The catalogue advances from schema 5 to schema 6. New `collections` and
`collection_items` tables use explicit positions, duplicate and position
constraints, timestamps and cascading foreign keys. SQLite and MySQL/MariaDB
receive equivalent structures. The migration creates empty collection tables;
it does not rewrite indexed media or require a rescan. SQLite performs the
normal verified pre-migration backup. MySQL/MariaDB operators must create their
external backup before first startup with 0.5.0.

This patch deliberately excludes Home-screen rows for manual collections,
manual up/down item reordering, music playlists, a screensaver, MyPicsDB2 import,
file export/copying, advanced multiselect and new metadata-filter families.

## Runtime acceptance

1. Back up the active database, then upgrade a schema-5 installation and confirm
   startup reaches schema 6 without a rescan.
2. Open **Collections**, create a collection, rename it and reopen it.
3. Add a still picture and a home video through their context menus.
4. Add the same item again and confirm no duplicate appears.
5. Restart Kodi and confirm item order is retained.
6. Remove one item from the collection and confirm its source file and normal
   catalogue entry remain.
7. Delete a collection and confirm all original media remains browsable.
8. Confirm the collection opens with **Default album view**.
9. Test a picture-only collection and a video-only collection. For a mixed
   collection, confirm the choice between **Play picture slideshow** and **Play
   video playlist**, including **Play slideshow from here** on a later item.
10. Temporarily make a source unavailable or mark a test row missing and confirm
    the collection opens without an exception.
11. With a minimum-rating policy enabled, confirm hidden pictures are omitted
    and the temporary all-pictures override is respected.
12. For SQLite, confirm a verified schema-5 backup exists under the add-on
    profile backup directory. For shared MariaDB, test from two Kodi clients
    after taking the external backup.
