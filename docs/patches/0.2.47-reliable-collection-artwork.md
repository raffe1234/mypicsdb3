# 0.2.47 reliable collection artwork

Version 0.2.47 makes album and date-group artwork independent of filename
heuristics. Catalogue queries now return the representative row's stored
`media_type`, and the browser passes that value to the common artwork resolver.
A video-only album therefore receives Kodi's native generated-frame URI even if
the video uses an uncommon extension or an extension added by the user.

MyPicsDB 3 still prefers a real picture over a video when selecting an album
representative. Collection list items publish the chosen artwork as `thumb`,
`icon`, `poster` and `landscape`, which covers both the normal browser and
Estuary poster widgets such as **Recent albums** and **Random albums**.

No schema migration or full scan is required. Existing schema-5 catalogue rows
already store `media_type`; the change only reads and exposes that field more
reliably. Kodi continues to generate and cache video frames lazily.
