# Scan duration in Scan status (0.4.6)

Version 0.4.6 adds timing information to the existing **Scan status** screen.
The latest completed scan shows **Scan duration**, calculated from the
`scan_runs.started_at` and `scan_runs.finished_at` values already stored in
schema 5. When Scan status is opened or refreshed, an active manual or
automatic scan shows **Elapsed time** from the session-local scan status
published on Kodi's Home window.

The formatter accepts SQLite timestamp strings and the `datetime` values that
PyMySQL can return for MariaDB. Missing, incomplete or invalid timestamps are
omitted rather than making the status screen fail.

No database migration, catalogue rescan, Estuary revision change or repository
add-on version change is required.
