# 0.3.2 Estuary widget captions

Version 0.3.2 fixes missing filenames and album names on the Estuary MyPicsDB 3
home screen. Estuary's stock poster widget is intended for films and does not
render a title beneath the poster, even when the plug-in publishes one.

The generated skin now adds a MyPicsDB-only poster include with a reserved
caption area. It reads `MyPicsDB3.WidgetLabel`, falls back to `ListItem.Label`,
and uses brighter scrolling text when the item has focus. Other Estuary widgets
are not modified.

The skin package revision is increased so Kodi installs the changed XML. The
plug-in database and indexed media are unchanged, so no rescan is required.
