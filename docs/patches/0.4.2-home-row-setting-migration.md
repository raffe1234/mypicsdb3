# 0.4.2 home-row setting migration

Version 0.3.5 introduced `home_widget_limit` even though existing installations
already stored the home-row count in `widget_limit`. The new setting defaulted
to 10, so a previously selected value such as 39 was no longer used.

Version 0.4.2 restores `widget_limit` as the only visible and authoritative
setting. On first start it compares the original and temporary values, preserves
the meaningful user value, writes it to both IDs for downgrade compatibility,
and records a hidden migration marker. The effective range remains 4-40.
