# MyPicsDB 3 0.2.34: saved searches

## Scope

This patch adds a small first saved-view feature on top of the existing
versioned Query Model. A user can save the current global text search, browse
**Saved searches**, reopen it with normal pagination and slideshow support,
and rename or delete it.

## Storage and safety

Database schema 5 adds `saved_searches` for both SQLite and MySQL/MariaDB. Each
row stores a bounded name, `query_version`, canonical `query_json`, and
timestamps. Saved-view plugin URLs contain the row ID rather than serialized
query JSON. No raw SQL is accepted or stored.

Every read checks the stored version, parses JSON, rejects unknown members and
passes the result through the Query Model allowlist before it can reach the
compiler. Corrupt or future-version rows produce a controlled Kodi error.

## Kodi checks

1. Run a global search and select **Save this search**.
2. Open **Saved searches** and verify pagination and **Play slideshow from
   here**.
3. Rename and delete a saved search from its context menu.
4. Restart Kodi and confirm that the saved search remains available.
5. Repeat with SQLite and, when configured, MySQL/MariaDB.
