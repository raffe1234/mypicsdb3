# 0.4.7 album picture-viewer fix

## Problem

Selecting a still picture inside an indexed album could show Kodi's busy cursor
and then leave the user on the thumbnail grid. Kodi logged
`VideoPlayer::OpenFile` for the JPEG path, which showed that the item had been
classified through video metadata rather than the native picture path.

## Fix

Media items now publish the custom `MyPicsDB3.WidgetLabel` caption without
creating a VideoInfoTag first. Actual video rows still receive their normal
VideoInfoTag in `_set_video_info()`, while folders and album tiles keep their
existing title metadata.

The change affects Recent albums, Random albums and every other indexed album or
picture-list route that uses `_media_item()`. Home-screen pictures and native
media-source browsing remain unchanged.

No database migration or catalogue rescan is required.
