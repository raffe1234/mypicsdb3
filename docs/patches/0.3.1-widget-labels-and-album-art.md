# 0.3.1 widget labels and album artwork

Version 0.3.1 restores the quiet filename and album-name captions used by
Estuary poster widgets. MyPicsDB 3 now publishes the visible label as both the
normal list-item label and the title consumed by Estuary's poster layout. A
`MyPicsDB3.WidgetLabel` property is also available to other skins.

Album cover selection now prefers broadly supported still formats (JPEG, PNG,
WebP, BMP, GIF and TIFF) before RAW/HEIF pictures, while still keeping Kodi's
generated video frame as the fallback for video-only albums. This changes only
which existing catalogue row is presented as artwork; no scan or schema change
is required.

Refreshing random selections also clears Estuary's shared horizontal widget
position before the skin reload. A newly shuffled row therefore starts at its
first item instead of inheriting a position from the previous result set.
