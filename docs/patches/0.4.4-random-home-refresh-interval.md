# 0.4.4: scheduled random home-row refresh

MyPicsDB 3 now exposes **Refresh random home-screen rows every (hours)** under
**Settings > Home screen**. The default is two hours and the accepted range is
1–720 hours.

## Behaviour

The background service starts the first interval when it starts. When the
interval expires it increments the Home-window property
`MyPicsDB3.RandomWidgetGeneration`. Only the bundled Random memories, Random
albums and On this day - random provider URLs contain that property, so Kodi
reruns those providers without invalidating Recently taken, Favorites, smart
collections or other MyPicsDB 3 rows.

## 0.4.5 stability follow-up

Version 0.4.5 derives a deterministic database pivot from the normal and random
generation values in each home provider URL. Kodi may request the same provider
more than once while rebuilding the home window; those repeated requests now
return the same pictures and order. A new selection is produced only after one
of the documented generation changes.

Changing the interval produces a new random selection immediately and starts a
new interval from that point. The existing **Refresh random selections** action
also advances the random generation. Catalogue-changing scans and relevant
home-screen changes continue to advance `MyPicsDB3.HomeWidgetGeneration`, which
refreshes every MyPicsDB 3 row including the random rows.

## Compatibility

- No database schema change or catalogue rescan is required.
- The normal widget endpoints and third-party skins are unchanged.
- The generated Estuary patch revisions are 12 for Kodi 21 Omega and 10 for
  Kodi 22 Piers.
