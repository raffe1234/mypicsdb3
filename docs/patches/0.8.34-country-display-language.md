# 0.8.34 — country display language

## Purpose

Make **Browse metadata > Location > Country** present country labels in Kodi's
current GUI language without changing the indexed country value or causing network
requests merely by browsing metadata. Also make the README's Unicode-search wording
language-neutral.

## Behaviour

- Kodi's active GUI language is requested from the Kodi API and passed to the
  country-localization Nominatim requests as `accept-language`.
- Exact provider-cache entries used by those language-specific requests are partitioned
  by requested language; established language-unspecified enrichment caches are unchanged.
- The new explicit **Localize country names for GUI language** action looks up at
  most one representative stored GPS coordinate per distinct raw country value.
- The returned country name is stored as a display-only alias keyed by GUI language
  and raw country value. Country filtering and global search still use the original
  indexed value.
- The Country facet and Location details use the alias when one exists and otherwise
  fall back to the indexed country text. Browsing remains local-only.
- The action requires Online reverse geocoding to be enabled and asks for confirmation
  before any lookup. Pictures, filenames, paths and raw country text are not sent.
- Country values with no stored GPS representative cannot be localized by this
  mechanism and retain their indexed display value.
- No database schema or Query Model version change is required.

## Documentation cleanup

README search documentation now describes Unicode normalization generically instead
of naming one language. The legacy-parity reference list explicitly includes the
MyPicsDB2 repository, and the 0.8.33 real-Kodi scan-progress note is updated from a
pre-tagging statement to post-release acceptance wording.

## Validation

Run the normal repository test suite, `tools/verify.py`, and the add-on build check.
The patch also adds focused coverage for Kodi GUI-language detection, Nominatim
language parameters/cache partitioning, country display aliases, raw-value-preserving
facet routes, representative-coordinate localization and catalogue candidate lookup.
