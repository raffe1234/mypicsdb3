# 0.8.31 background whole-library metadata refresh

Version 0.8.31 moves **Refresh all picture metadata** from a modal foreground progress dialog to Kodi's non-modal background progress UI.

The refresh remains serial, resumable and protected by the existing metadata-refresh catalogue lock. It does not modify source files and does not perform online reverse geocoding.

## Runtime behavior

- Confirmation/resume/restart remains foreground and explicit before work begins.
- The long-running refresh uses `DialogProgressBG` and publishes session-local progress through Home-window properties so later plug-in invocations can display status or request a soft stop.
- Browse metadata replaces the start action with current progress plus **Stop metadata refresh** while the operation is active.
- A stop request is observed at the existing per-picture cancellation boundary; `MetadataRefresher.refresh_all()` writes the established checkpoint and a later run can resume it.
- When **Pause scanning during playback** is enabled, whole-library metadata refresh pauses while Kodi is playing media and resumes automatically afterwards. The background progress dialog stays out of the way during playback.
- Kodi/add-on shutdown is treated as an interruption and leaves the resumable checkpoint path intact.

## Compatibility boundaries

- Plug-in: 0.8.31
- Database schema: 9
- Query Model: 1
- Repository add-on: 0.2.26
- Folder metadata refresh: unchanged foreground workflow
- Scanner and metadata-refresh writers: still serial
