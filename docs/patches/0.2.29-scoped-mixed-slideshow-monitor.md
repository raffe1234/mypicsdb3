# MyPicsDB 3 0.2.29: scoped mixed-slideshow monitor

## Problem

Version 0.2.28 moved recursive album slideshows to Kodi's native
`SlideShow(...,recursive,notrandom)` path. The background
`MixedSlideshowVideoMonitor` nevertheless continued to call
`Player.GetActivePlayers` every 0.5 seconds throughout the Kodi session.

Because the monitor identified indexed videos rather than the slideshow that
started them, it could also observe a native album slideshow and issue
`Player.GoTo(next)` when Kodi returned from video playback. That violated the
0.2.28 design goal that Kodi should own native album playback completely.

## Change

- A Home-window property marks only MyPicsDB 3 database-backed playlists that
  contain video as active. Photo-only result sets keep the monitor dormant.
- The service performs no slideshow JSON-RPC polling while that property is
  absent.
- Starting a native recursive album slideshow explicitly clears the property.
- Starting a database-backed result-set slideshow arms the monitor and clears
  the state again if playlist startup fails.
- The service clears the property after the picture/video players disappear.
  A short startup grace period avoids clearing it before `Player.Open` has
  produced an active Kodi player.

The property is session-local. It is not written to settings, the database or
original media.

## Compatibility

- Database schema remains version 4.
- Repository add-on remains version 0.2.26.
- Native folder slideshow behavior from 0.2.28 is unchanged.
- Database-backed result sets still use picture playlist 2 and retain the
  video-to-picture advance workaround.

## Verification

Automated tests cover:

- zero JSON-RPC polling while the monitor is inactive;
- remaining inactive for photo-only database playlists;
- arming for database-backed playlists containing video;
- disarming before native album slideshows;
- video-to-picture advancement for an armed session;
- startup grace and stale-session cleanup;
- the shared Kodi Home-window property.

Real Kodi A/B testing is still required for photo-only and mixed playlists,
including video first, middle and last, consecutive videos, stop, skip and
local versus SMB/NFS media.
