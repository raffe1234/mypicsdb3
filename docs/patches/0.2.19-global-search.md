# Patch report: 0.2.19 global search

## Scope

This release adds the first user-facing global search built on Query Model
version 1. It raises the catalogue from schema 2 to schema 3 with one normalized
search document per picture.

Included:

- a **Search** entry and Kodi keyboard dialog on the add-on main menu;
- Unicode NFKC/casefold tokenization with Swedish letters retained;
- AND semantics for multiple words;
- filename, caption, keyword, path, camera and location tokens;
- schema-3 fresh-database definitions and an idempotent batch backfill;
- search-document maintenance during scanner inserts and updates;
- Query Model `text` / `contains_tokens` validation and safe compilation;
- minimum-rating policy and temporary all-picture override support;
- browser pagination with normalized search text preserved;
- SQLite, Kodi UI and opt-in MariaDB migration/query coverage.

Not included:

- phrase, fuzzy, prefix or AI search;
- FTS5 or FULLTEXT requirements;
- result relevance weighting;
- search history;
- saved views, smart filters or collections;
- generic metadata facets or lens metadata.

## Migration notes

SQLite creates an atomic, integrity-checked backup before applying schema 3.
The migration creates `picture_search_documents`, clears any partial contents
left by an interrupted backend DDL attempt and rebuilds documents in batches of
500 pictures.

MySQL/MariaDB DDL can commit implicitly. Operators must create an external
backup before installing 0.2.19. Retrying the migration is safe because search
documents are derived data and are rebuilt from `pictures`, `picture_tags` and
`tags`.

   finish without closing Kodi.
2. Confirm **Search** is visible near the top of the MyPicsDB 3 main menu.
3. Search by filename, caption, keyword, camera, path and location.
4. Confirm `å`, `ä` and `ö` match regardless of letter case.
5. Confirm two words require both words on the same picture.
6. Set a minimum rating and verify search respects it.
7. Use **Show all pictures temporarily**, search again and verify pagination
   retains the override.
8. Restart Kodi and confirm normal browsing and incremental scanning still work.
9. Inspect `meta.schema_version = 3`, migration rows 1–3 and one search document
   per indexed picture.
10. Record warm and cold search times on the real library.
