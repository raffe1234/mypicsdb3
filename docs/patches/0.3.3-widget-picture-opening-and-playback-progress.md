# 0.3.3 widget picture opening and playback-safe scan progress

Version 0.3.3 fixes the OK/Enter action on MyPicsDB home-screen widgets. Kodi's
dynamic widget fallback treated non-folder picture rows as playable media, so a
JPEG or NEF was opened briefly by `VideoPlayer` and closed at end-of-file. The
Estuary MyPicsDB 3 widget now uses explicit actions:

- `ShowPicture` for still pictures;
- `PlayMedia` for indexed home videos;
- `ActivateWindow(Pictures,...)` for album folders.

The plug-in publishes an escaped, stable widget path for each row, preserving
SMB/NFS paths with spaces, commas, quotes and non-ASCII characters.

Automatic scans remain non-modal, but their progress dialog is now hidden while
Kodi is playing media. This covers Live TV, TV episodes, movies and other
playback. If the setting permits scanning during playback, the scan continues
silently, its shared status remains available to the MyPicsDB **Scan status**
view, and the progress dialog returns after playback stops.

No database migration or catalogue rescan is required.
