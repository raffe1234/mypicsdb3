# 0.2.48: random refresh and decoder guidance

This maintenance release adds a **Refresh random selections** action that asks
Kodi to rerun the random picture, album and On this day providers. Estuary
MyPicsDB 3 is reloaded so its home-screen rows refresh as well; no filesystem
scan or database mutation is performed.

The README now names the Kodi binary image decoders required for common optional
formats: **Libraw image decoder** for supported RAW files such as Nikon NEF and
**HEIF image decoder** for HEIC/HEIF. It also explains when installing a decoder
requires a rescan.

Automatic and manual scans now log whether cancellation was requested by the
user or caused by Kodi/add-on service shutdown. Exact resume checkpoints remain
outside this release; a later scan traverses sources from the root while normal
incremental checks skip unchanged media.
