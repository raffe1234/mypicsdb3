# 0.4.11 inline Home-row controls

The combined Home editor introduced in 0.4.9 kept its main actions on the right,
but selecting a row still opened a second action dialog before it could be
enabled or moved. Smart collections also exposed Poster, Square and Wide as a
separate per-row setting even though normal interactive browsing already uses
**Default album view**.

Version 0.4.11 reuses the existing XML row grid for the mixed built-in and smart
layout. Each visible row now has an inline On/Off switch and dedicated up/down
buttons. Ten rows are shown at once; remote or mouse movement past the first or
last visible row scrolls the editor without changing the underlying order.
Save, Cancel, Defaults and Add smart collection remain persistent on the right.
Remove smart collection appears there when the selected row is a smart
collection.

Smart rows now use the standard MyPicsDB poster widget in generated Estuary
packages. The editor no longer asks for a display mode. Existing
`home_layout_v2` values containing `square` or `landscape` remain readable and
are normalized to `poster`; the hidden mode setting/property is retained only
for downgrade compatibility. Opening a saved smart collection through normal
plug-in browsing continues to apply **Settings > General > Default album view**.
Widget providers remain read-only and do not force a view mode.

The plug-in advances to 0.4.11. Estuary revisions advance to 15 for Kodi 21
Omega and 13 for Kodi 22 Piers. Database schema 5, Query Model 1, Home-layout
format 1 and repository add-on version 0.2.26 are unchanged. No rescan or
migration is required.

## Runtime acceptance

1. Open **Settings > Home screen > Configure home-screen rows**.
2. Confirm every row has an inline On/Off switch and up/down arrows.
3. Move rows repeatedly across the tenth-row boundary and confirm the list
   scrolls while the moved row remains focused.
4. Add a saved smart collection, move it, disable/enable it and save.
5. Reopen the editor and confirm order and state persisted.
6. Confirm no Display mode prompt appears.
7. Open the smart collection through normal browsing and confirm **Default album
   view** is used.
8. Confirm the Home smart row uses the standard picture-row layout and opens its
   pictures normally.
9. Remove the smart row and confirm the saved search itself still exists.
10. Check the Kodi log for editor initialization errors or Python exceptions.
