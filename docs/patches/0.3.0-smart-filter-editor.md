# 0.3.0: smart filter editor

Version 0.3.0 is the first MyPicsDB 3 feature release after the 0.2.x
stabilisation series. It adds a Kodi-native editor that creates reusable smart
collections from the existing validated Query Model.

## User flow

1. Open **MyPicsDB 3 > Create smart collection**.
2. Choose **All criteria** or **Any criterion**.
3. Add, edit or remove criteria for text, date range, minimum rating, favorite,
   source, camera, keyword or media type.
4. Choose the result order and whether the global minimum-rating policy applies.
5. Select **Preview results** to see the count and up to ten filenames.
6. Save a unique name. The collection opens immediately and remains available
   under **Saved searches**.

## Safety and compatibility

The editor emits only Query Model version-1 objects. Every draft is parsed and
validated before preview or storage, SQL fragments remain allowlisted and all
values are bound parameters. Plug-in URLs contain only the saved-search row ID.

Query Model version 1 now accepts `media_type eq picture|video` and the
corresponding `in` list. Existing saved searches remain compatible. The release
uses the existing schema-5 `saved_searches` table and requires no database
migration or media rescan.
