# 0.8.21 Estuary Pictures control-id cleanup

The generated Pictures Home group previously assigned MyPicsDB slot 9 the panel
control id `5000`. Official Estuary already uses id `5000` for the complete Movies
Home group, so both controls existed in the same `Home.xml` window with the same
id. This release moves slot 9 to the otherwise unused Pictures-local id `4950`.

The Pictures widget scrollbar now also follows official Estuary behavior and is
visible only when `Skin.HasSetting(touchmode)` is true. The vertical page control
remains present because MyPicsDB can expose several picture rows.

This is deliberately a skin-only correctness/performance follow-up. It does not
change scan concurrency, filesystem I/O, database schema 9, Query Model version 1,
provider queries, widget limits, media files or Kodi's texture cache.
