# 0.2.39 adaptive mixed-slideshow player

## Runtime evidence

On Kodi 21.3 for Windows, JSON-RPC accepted picture playlist 2 but opened the
first JPEG with `VideoPlayer`. FFmpeg then identified every JPEG as MJPEG and
reached end-of-file in well under the configured picture display duration. The
same explicit mixed playlist continued to work on the forum tester's CoreELEC
installation.

## Change

Before committing to the explicit mixed route, MyPicsDB 3 starts a known picture
from the completed playlist and polls `Player.GetActivePlayers`. If the active
video player's `Player.GetItem` file is that exact picture, the add-on stops the
incorrect player and clears the playlist.

A folder-tree action then starts Kodi's native recursive slideshow, which is the
working route on the maintainer's Windows installation. Database result sets
that span unrelated folders instead restart with indexed pictures only and show
an explanatory notification.

If Kodi reports a picture player, the explicit playlist remains active and a
requested non-zero start position is opened after the probe. An inconclusive
probe does not abort playback.

## Privacy and scope

The probe compares media URIs in memory but does not write them to the log. The
fallback log records only route, scope, counts and the player-mismatch reason.
Database schema 5 and repository add-on 0.2.26 are unchanged.
