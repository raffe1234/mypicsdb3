# 0.8.16 — Collection snapshots

Version 0.8.16 added **Save current results as collection** for global search,
saved smart collections, Browse metadata result pages and Needs attention result
pages.

A snapshot freezes the complete current validated result set, not only the
visible page. The ordered catalogue IDs are selected once and inserted into a
manual collection transactionally, preserving deterministic order. The snapshot
stores no Query Model JSON and copies no source files.

The action routes remain reference-only: search text, saved-search ID, curated
metadata facet/value or built-in preset key are reconstructed and validated
server-side. Raw SQL and raw Query Model JSON are never accepted from Kodi route
parameters.

- Query Model: 1
