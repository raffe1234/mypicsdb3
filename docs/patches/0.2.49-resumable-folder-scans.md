# 0.2.49: resumable folder scans

This release adds a local scan-checkpoint file under the Kodi add-on profile.
The scanner advances it only after every catalogue change for a fully processed
folder has been committed. If Kodi, an add-on update or a user stop interrupts
the next folder, that folder remains on the saved depth-first traversal frontier
and is processed again safely when a compatible scan resumes.

The checkpoint keeps the original source-scan timestamp, partial counters, the
remaining folder stack and the IDs of sources already completed. This preserves
source-wide missing-record detection without adding a catalogue table or changing
schema 5. A prior directory-listing failure is also retained, so a resumed source
remains partial and cannot mark unseen rows missing.

Checkpoints are atomic, local to one Kodi profile and limited to 24 hours. The
source list, database identity and scan-affecting settings are hashed into the
checkpoint signature. A changed extension list, video setting, exclusion or
metadata option therefore discards the old state and starts a clean traversal.
