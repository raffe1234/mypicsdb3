# 0.8.30 DialogProgress compatibility

Version 0.8.30 fixes the foreground progress UI used by explicit folder and whole-library metadata refresh.

## Root cause

Kodi 19 and later expose `xbmcgui.DialogProgress.update(percent, message)`. The refresh UI still passed the pre-Python-3 multi-line positional form `(percent, line1, line2)`. On a real Kodi 21 installation, the 0.8.29 whole-library refresh therefore reached the confirmation dialog but could fail on the first progress callback. The exception was intentionally caught by the UI layer and shown as a metadata-refresh error notification, so no Python traceback was required in `kodi.log`.

## Fix

- Use the supported two-argument foreground progress API.
- Preserve both the numeric counter and current filename in one newline-separated message.
- Apply the same correction to folder metadata refresh, which shared the legacy call pattern.
- Make the Kodi UI test double enforce the modern signature.

## Compatibility

- Plug-in: 0.8.30
- Database schema: 9 (unchanged)
- Query Model: 1 (unchanged)
- Repository add-on: 0.2.26 (unchanged)
- No source-file writes, online reverse-geocoding changes, scanner changes or Estuary revision are introduced.
