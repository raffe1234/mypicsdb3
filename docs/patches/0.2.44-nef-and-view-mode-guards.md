# 0.2.44 NEF support and view-mode guards

Version 0.2.44 adds `nef` to the default scanner extensions and the slideshow
still-picture classifier. An installation that still has the exact pre-0.2.44
default extension list is upgraded automatically. User-customized lists are not
changed. Kodi requires the optional **Libraw image decoder** binary add-on to
display Nikon RAW files; MyPicsDB 3 does not bundle or install that decoder.

The release also narrows when the configured album view may be requested. The
Pictures window (10002) must be active, no modal dialog may be open, and Kodi's
container must have finished updating. Empty picture results do not request a
view. These checks prevent stale category/content labels behind the picture
player or another window from triggering `Container.SetViewMode`.

When MyPicsDB 3 debug logging is enabled, the log now records the target view,
current view, attempt number, cancellation and successful verification. This is
diagnostic hardening rather than a guarantee that every skin exposes every view
control for every type of result.

Database schema 5, Query Model version 1 and repository add-on version 0.2.26
remain unchanged.
