# 0.5.1 manual collection Home rows and ordering

Version 0.5.1 completes the first manual-collection workflow without changing
the schema. A manual collection can now be added to the same Pictures-home row
editor as built-in views and saved smart collections. **Add collection** asks
whether to add a smart or manual collection, after which the row uses the same
inline On/Off switch and up/down controls introduced in 0.4.11.

Each enabled manual row is materialized as a collection ID and current name in
one of nine hidden settings and Home-window properties. The generated Estuary
fragment calls the fixed `home-collection?slot=N` route, avoiding nested setting
expressions and keeping stale IDs out of the skin. Opening a row uses **Default
album view**. Rename, content and order changes invalidate the Home generation;
deleting a collection removes its row.

Inside a manual collection, item context menus now expose **Move up**, **Move
down**, **Move to top** and **Move to bottom** where applicable. The catalogue
reorders pictures and home videos in one shared list. It preserves membership
timestamps and replaces the ordered membership rows inside one transaction before
writing compact positive positions. This preserves the unique position constraint
and supports MySQL/MariaDB unsigned positions. Removing an item also compacts the
remaining positions. Original files and catalogue media rows
are never changed.

Catalogue schema 6 remains current. Updating from 0.5.0 requires no migration,
new backup or rescan. Generated Estuary revisions advance to Omega 16 and Piers
14.

## Runtime checks

1. Add a manual collection from **Configure home-screen rows** and move it across
   the ten-row editor viewport boundary.
2. Toggle it off and on, save, restart Kodi and verify order and state.
3. Rename the collection and verify the Home heading.
4. Add, remove and reorder mixed picture/video items and verify the Home row.
5. Test all four move actions and verify order after restart.
6. Delete the collection and verify that its Home row disappears safely.
7. Open an empty collection and one containing a missing item.
