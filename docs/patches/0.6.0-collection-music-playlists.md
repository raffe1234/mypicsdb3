# 0.6.0 collection music playlists

This patch adds one optional Kodi music-playlist reference to saved smart and
manual collections and reorganizes the README feature overview.

## User-visible behaviour

- Collection context menus can assign, change and remove a playlist selected
  from Kodi music sources.
- Assigned collections show **Play picture slideshow with music**.
- Music playback is explicit and picture-only; normal video and mixed playback
  is unchanged.
- The service stops music after the native slideshow only when the current
  queue still matches the queue started by MyPicsDB.

## Storage and upgrade

- Add schema 7 table `collection_music_playlists`.
- Store only target type, target ID, playlist URI and update time.
- Remove mappings transactionally when their smart/manual target is deleted.
- SQLite performs the normal verified pre-migration backup.
- MySQL/MariaDB requires the operator's normal external backup.
- No catalogue rescan is required.

## Safety choices

- Playlist files and music files are never copied, parsed, modified or deleted.
- Missing, unreadable and empty playlists fail before picture playback starts.
- Videos are excluded from music slideshows rather than pausing or mixing audio
  players around video playback.
- A changed Kodi music queue is treated as replacement playback and is not
  stopped by MyPicsDB cleanup.

## Validation

Run the full automated test suite, `tools/verify.py` and
`tools/build.py --skip-skin`. Runtime validation must cover both collection
types, assignment persistence, empty/missing playlists, slideshow exit cleanup
and replacement-audio safety before tagging `v0.6.0`.
