# MyPicsDB 3 0.2.36: verified Kodi view modes

## Scope

Kodi may restore a path-specific remembered view after the plug-in has already
requested the configured album view. In 0.2.35 this could leave a new search in
Shift even when **Default album view** was set to Wall.

## Behaviour

The add-on waits for the expected picture container to remain stable, sends the
configured view as a blocking built-in and verifies the active picture-window
view control. The target must remain active briefly. If Kodi performs a late
restore to another remembered view, MyPicsDB retries up to two more times while
the same category and content remain active.

The total wait is bounded. Navigating away cancels pending retries, so the root
menu, Saved searches and widget layouts are not changed. Database schema 5 is
unchanged.

## Kodi checks

1. Set **Default album view** to Wall.
2. Keep the MyPicsDB 3 root menu in Wide list.
3. Open a new text search and verify that the result remains Wall.
4. Return to the root menu and verify that it remains Wide list.
5. Repeat with a saved search and **Open containing album**.
