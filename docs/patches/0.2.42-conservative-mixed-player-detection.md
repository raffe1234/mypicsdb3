# 0.2.42 conservative mixed-player detection

Kodi 21.3 on Windows can advance through JPEG files as one-frame MJPEG videos
faster than the add-on can poll the exact first item. Version 0.2.41 therefore
logged an inconclusive probe and later cached the route as compatible.

Version 0.2.42 treats an inconclusive probe or full-playlist verification as an
incompatibility. It also rejects any active `VideoPlayer` item whose URI has a
known still-picture extension. Folder-tree requests then use Kodi's native
recursive slideshow fallback before the full explicit mixed playlist is built.

The compatibility Home-window property is versioned to invalidate false
positive values cached by 0.2.41 during the same Kodi session.

Picture-only database result sets continue to use picture playlist 2 without
mixed-media probing.
