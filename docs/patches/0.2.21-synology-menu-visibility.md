# MyPicsDB 3 0.2.21: Synology exclusions and menu visibility

## Scope

This schema-free patch addresses two user reports:

1. Synology NAS `@eaDir` metadata trees must never be indexed as original
   pictures.
2. Users must be able to hide catalogue browsing nodes they do not use from the
   MyPicsDB 3 add-on menu.

Video indexing and mixed photo/video playback are not included. That work needs
an explicit media model, video metadata handling and a playback design rather
than adding video extensions to the existing picture-only scanner.

## Synology directories

The scanner now treats every directory whose name ends with `@eaDir`,
case-insensitively, as a built-in system exclusion. The check is independent of
`exclude_fragments`, because older Kodi profiles can retain an empty or outdated
saved setting.

The check runs before the directory is added to the scan stack and again before
an active stack entry is processed. This also covers a source that points
straight at an `@eaDir` tree.

A normal rescan no longer touches previously indexed Synology thumbnails, so
`mark_missing_after_scan` removes them from active catalogue views. The existing
missing-record retention and cleanup controls remain unchanged.

## Add-on menu visibility

**Settings > General > Configure add-on menu** opens Kodi's multi-select dialog
for these nodes:

- Recently taken
- Recently added
- Random memories
- Recent albums
- Random albums
- On this day
- Years
- Cameras
- Keywords
- Favorites
- Rated pictures
- Geotagged pictures

The setting stores only hidden node keys in stable order. Empty or missing
settings therefore preserve the old behavior in which every node is shown.
Search, Picture sources, Scan now, Scan status and Settings are always present.

## Compatibility

- Database schema remains version 3.
- Existing home-screen row configuration is unchanged.
- SQLite and MySQL/MariaDB catalogue behavior is unchanged.
- Existing custom file and path exclusion fragments are still applied.

## Verification

Automated tests cover:

- an `@eaDir`-suffix tree with no custom exclusions;
- validation and stable serialization of hidden menu keys;
- default main-menu compatibility;
- hiding selected nodes while retaining management actions;
- saving the multi-select result;
- settings XML registration.
